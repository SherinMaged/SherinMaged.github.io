# موقع د. شرين ماجد — النسخة الأولى (مسودة للمراجعة)

## الملفات
- `index.html` — الصفحة الرئيسية (كل الأقسام في صفحة واحدة)
- `privacy.html` — صفحة الخصوصية وإحصاءات الزيارة
- `assets/style.css` — التنسيقات والألوان
- `assets/reader.js` — أدوات القراءة (تكبير النص + تباين مرتفع) لضعاف البصر
- `assets/analytics.js` — فارغ حاليًا؛ تُفعَّل الإحصاءات عند النشر فقط

## الأقسام
عنّي، خدماتي (التعليق الصوتي والدوبلاج، تدريب الأطفال على الإلقاء، تدريب التقنيات المساعدة، التدقيق اللغوي)، أعمالي (روابط يوتيوب)، في الصحافة (نص مؤقت بانتظار المقابلات)، للأطفال (قناة أطفال البرنامج العام + الألعاب قريبًا)، تواصل معي (بريد + واتساب + شبكات).

## الوصولية (مهم)
الصفحة مبنية بعناوين وأقسام دلالية مرتبة، ورابط «تخطَّ إلى المحتوى»، وروابط وأزرار لها أوصاف واضحة لقارئ الشاشة، وتباين ألوان مرتفع، وتكبير نص حتى ٢٠٠٪.

## كيف تتم التعديلات
ترسلين التعديل بالواتساب، وأنا أنفذه على الملفات وأرجعلك الوصف بالكلمات قبل النشر.

## النشر (عند الموافقة فقط)
استضافة مجانية على GitHub Pages أو GitLab Pages، باسم مثل sherinmaged.github.io.
اختياري لاحقًا: لوحة تعديل داخل المتصفح (Decap CMS) وإحصاءات زيارات خاصة (GoatCounter أو بديل).
